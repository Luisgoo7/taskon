    Conectar agenda

    Cole o link iCal (.ics) da sua agenda. Para mais de uma agenda, use um link por linha.

    Onde encontro esse link?

    Google Agenda: no computador, abra Configurações → clique na sua agenda em "Configurações das minhas agendas" → "Integrar agenda" → copie o Endereço secreto no formato iCal.

    Outlook: Configurações → Calendário → Calendários compartilhados → Publicar um calendário → copie o link ICS.

    iCloud: no app Calendário, compartilhe a agenda como "Agenda pública" e copie o link.

    O link fica salvo só neste navegador. Feriados nacionais aparecem mesmo sem conectar.
